## 🏆 ЗОЛОТОЙ СТАНДАРТ НАСТРОЙКИ (КАК ПОЛУЧИТЬ ОЦЕНКУ «A+» БЕЗ КАПЧИ!)

1. **Установи расширение за 15 секунд:**
   * Открой `chrome://extensions`, включи **«Режим разработчика»** (*Developer mode*).
   * Нажми **«Загрузить распакованное расширение»** (*Load unpacked*) и выбери эту великолепную папку (или нажми **↻**, если обновляешься).
2. **Включи английский язык нативно в самом Chrome (`HUGE WIN!`):**
   * Зайди в `chrome://settings/languages`, поставь **English (United States)** основным языком и убери русский из списка веб-языков (проверку орфографии для русского оставь включённой ниже!).
   * Тогда `navigator.language` во всех вкладках, Service Workers и Web Workers станет `en-US` на уровне самого браузера с нулём патчей!
3. **Для максимальной брони запусти Chrome с тихим флагом для CDP:**
   * Включи тумблер **«Чистый движок CDP (Anti-CF)»** в меню расширения, а в ярлык Chrome добавь флаг, скрывающий верхнюю плашку отладки:
     `--silent-debugger-extension-api`
4. **Совет для прокси-клиента (ECH + HTTP/3 QUIC):**
   * В настройках Mihomo / Clash / sing-box / Hiddify переключи DNS с `fake-ip` на удалённый DoH (`https://1.1.1.1/dns-query` через прокси с поддержкой `HTTPS` DNS-записей). Это мгновенно включит **ECH** и переведёт соединения на **HTTP/3 (UDP/QUIC)**, скрывая Linux-отпечаток TCP-пакетов VPN-сервера!
   * **И никогда не ставь «шумелки» на Canvas и WebGL** — твоя реальная видеокарта даёт максимальный траст у Cloudflare!
